# Welcome to Portfolio 

A modern, minimal, and multi-page developer portfolio built using HTML, CSS, and Vanilla JavaScript.

Designed to showcase:
- projects
- technical skills
- open-source work
- communities
- personal identity

The website focuses on clean layouts, calm animations, structured hierarchy, and a premium dark-first experience without unnecessary visual noise.

---

## Features

- Multi-page architecture
- Premium dark/light theme system
- Responsive design
- Structured project showcase
- Community ecosystem page
- Animated but restrained UI
- SEO-ready structure
- Clean URL routing
- Contact form with backend protection
- Smooth page transitions
- Accessible and performance-focused design

---

## Pages

### Home
Minimal landing page with:
- introduction
- avatar
- role pills
- social links
- navigation CTA buttons

### About
A narrative-style page explaining:
- who I am
- my background
- why I started building
- what I currently work on

### Projects
Structured project showcase with:
- featured projects
- project hierarchy
- dedicated project pages
- stack information
- GitHub/demo links

### Communities
Organized ecosystem page displaying:
- developer communities
- technical groups
- projects and initiatives

### Contact
Minimal contact system with:
- name/email inputs
- social handle selector
- message form
- spam protection
- backend validation

## Tech Stack

### Frontend
- HTML5
- CSS3
- Vanilla JavaScript

### Backend
Used only for:
- form handling
- rate limiting
- spam prevention
- email delivery

---

## Design Philosophy

This project avoids:
- excessive animations
- visual clutter
- overengineered frameworks
- template-like UI

Instead, it prioritizes:
- readability
- hierarchy
- clarity
- subtle motion
- maintainability
- proof-of-work presentation
